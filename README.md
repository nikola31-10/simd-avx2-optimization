# SIMD Optimization Using AVX2

A university project focused on optimizing data processing using SIMD (Single Instruction, Multiple Data) instructions.

The goal was to improve the performance of array processing operations by using AVX2 intrinsics to process multiple elements simultaneously.

## Key Features
- Vectorized processing of integer arrays
- AVX2 intrinsics for parallel computations
- Efficient range checking and element counting
- Comparison between scalar and SIMD approaches

## Technologies
- C++
- AVX2 Intrinsics
- SIMD Programming
- GCC
- Linux

## Implementation
Implemented a SIMD-optimized function that counts the number of elements within a specified range in an array of unsigned integers.

The solution uses 256-bit vector registers to process multiple integers in parallel, reducing the number of sequential operations.

## Project Overview
This project strengthened my understanding of low-level optimization, CPU vector instructions, memory alignment, and performance-oriented programming.
